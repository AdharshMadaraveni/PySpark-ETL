## ETL Pipeline for Sensor Data using PySpark and Databricks

### Project Overview
This project demonstrates a simple ETL pipeline using PySpark on Databricks.
Synthetic IoT sensor data is generated, cleaned, transformed, and stored in Delta format.

### Technologies Used
- PySpark
- Databricks Community Edition
- Delta Lake
- Spark SQL

### Steps in the Project
1. Generate raw sensor data with dirty records
2. Apply schema validation and data cleaning
3. Transform data with business logic
4. Load data into Delta tables
5. Perform SQL-based analytics

### Key Learnings
- ETL pipeline design
- Data quality handling
- Delta Lake usage
- Time-series SQL analytics
